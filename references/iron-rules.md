# CNKI 批量导出 16 条实战铁律

每条来自真实翻车复盘。逐条理解"为什么"，而非死记"必须"。

## 1. 检索词要准确（标点 + 更名史）

CNKI 刊名可能与常见写法不同：

- **句点 vs 间隔号**："课程.教材.教法"用句点，写成"课程·教材·教法"检索结果从 11511 条骤降到 996 条，几乎全军覆没。
- **全角 vs 半角括号**：CNKI 用半角"()"，全角"（）"会搜不到。如"苏州大学学报(教育科学版)"。
- **期刊更名**："国际中文教育(中英文)"在2020年旧名"国际汉语教育(中英文)"，只按新名搜会漏掉旧年份。

**做法**：检索前用 `cnki-journal-search` 查准确刊名，或让用户确认。更名期刊要分别搜新旧名再合并。

## 2. 同名期刊用精准复选框锁定

CNKI 文献来源是模糊匹配。刊名是其他刊名子串时必然混刊：

- "教育学报" 混入 "比较教育学报""教师教育学报""高等继续教育学报"
- "高等教育研究" 混入其他"高等XX研究"
- "研究生教育研究" 混入 "学位与研究生教育"

**做法**：输入刊名后等自动补全出现，勾选自动补全列表中**精确刊名**左侧的复选框。这是唯一可靠的锁定期刊方式。

## 3. 选字段后折叠下拉

点 `.sort-default` 选字段（如文献来源）后，下拉菜单保持展开，会**遮挡全选复选框**导致点击失败。

**做法**：选完字段后再点一次 `.sort-default` 折叠。之后每次出现下拉遮挡都这样折叠。

## 4. 先核验来源纯净度再批量

不要一次批量导出几百条才发现混刊。先只勾第1页、导出、检查 `Source-文献来源` 列是否唯一且等于目标。

混刊 → 回第2步加复选框。纯净 → 才放心批量。

## 5. 停止判断看整页年份，不是首篇

逐页选择时，判断"该停了吗"必须看**页面所有论文的年份**，不能只看首篇。

错误做法：页面首篇是2019就停，导致2020年论文（同一页靠后位置）被漏掉。

正确做法：提取页面所有 `\d{4}-\d{2}-\d{2}` 日期，只要还有 ≥ 目标起始年（如2020）的就继续选，只有整页都 < 起始年才停止。

## 6. 导出格式精确匹配"自定义"

导出格式列表里有"自定义"和"查新（自定义引文格式）"两项，文本极像。选错会得到7列或12列而非18列。

**做法**：用精确文本匹配 `innerText.trim() === '自定义'`，绝不点击"查新（自定义引文格式）"。导出前检查列数=18。

## 7. 导出页也要重新选"自定义"格式

主页面点"自定义"只是打开导出页，导出页里格式列表**默认选中"查新（自定义引文格式）"**。必须在导出页的 `ul.formatlist li` 里再点一次"自定义"，确认 `li.className.includes('current')`，此时字段checkbox从约12个增到约23个。

## 8. 点 xls 后等 15 秒（验证码）

验证码在**点击 xls 下载按钮之后**才弹出，不在打开导出菜单时。如果点完xls立刻关闭导出页，验证码来不及处理，文件不会下载。

**做法**：点 xls 后等 15 秒（期间验证码弹出则停下让用户手动点击），再关闭导出页。

## 9. 批次间导航用"首页 + 精准翻页"

清除选择后再点"下一页"，CNKI 可能跳页（跳过多页或回到首页），导致批次重叠或漏页。

**做法**：每批导出后，点"首页"回到第1页，再精准点"下一页"N次到下一批起始页。不要连续快速点"下一页"。

## 10. 合并严格按来源名精确过滤

合并多个批次时，模糊匹配（如含"教育科学"）会把其他期刊混进来。曾出现"研究生教育研究"文件混入1106篇"学位与研究生教育"。

**做法**：合并时只保留 `Source-文献来源 == 目标刊名` 的行，用精确相等判断，不用 contains。

## 11. 最终按标题去重

批次重叠、导航跳页会导致重复记录。合并后必须 `drop_duplicates(subset='Title-题名')`，并对每个最终文件按标题再做一次去重检查。

## 12. 逐本核验三要素

每本期刊导出后，立即核验：

1. **字段完整**：18列，列名 = `SrcDatabase-来源库, Title-题名, Author-作者, Organ-单位, Source-文献来源, Keyword-关键词, Summary-摘要, PubTime-发表时间, FirstDuty-第一责任人, Fund-基金, Year-年, Volume-卷, Period-期, PageCount-页码, CLC-中图分类号, ISSN, URL, DOI`
2. **来源单一**：Source列唯一值 = 目标
3. **年份覆盖**：目标起始年到当前年，每年都有数据，且篇数不异常偏低（某年 < 平均30% 要查因）

任一项不通过 → 记录缺陷，立即修复或重爬，不得跳过进入下一本。

## 13. 期刊出版周期决定期数完整性

用"年 + 卷 + 期"判断完整性更准。月刊12期/年、双月6期/年、季刊4期/年、半月刊24期/年、旬刊36期/年。

但注意：有些期刊期号特殊（如半月刊用1-12和17-24，跳过13-16），需结合实际期号分布判断，不能机械套周期。

## 14. 每期发文量大致均匀

同一期刊每期发文量通常稳定。某年某期篇数异常（如0篇或1篇）往往意味着漏爬，而非期刊真的少发。

**做法**：统计每年每期篇数，找异常低的期，回去补。

## 15. 单页选择需触发完整事件链

CNKI 全选复选框不能只 `cb.checked = true`，计数不会更新。需：

```javascript
cb.checked = false;
await sleep(100);
cb.dispatchEvent(new MouseEvent('click', {bubbles: true, cancelable: true}));
await sleep(300);
if (typeof cb.onclick === 'function') cb.onclick();  // 触发 CNKI 的 filenameClick
```

只有触发 onclick 后，"已选"计数才会正确累加。

## 16. 每次 evaluate 先覆盖 alert

CNKI 超过500条选择时弹 `alert("不能超过500个...")`，在 evaluate 上下文中无法捕获，会阻塞后续所有操作。

**做法**：每次 `page.evaluate` 开头加 `window.alert = function(){}` 抑制。并控制每批不超过500条（约10页）。
