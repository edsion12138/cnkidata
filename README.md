# cnkidata — 知网批量数据导出 Skill

从知网（CNKI）批量导出**结构化文献数据**为 18 列 xlsx 表格。适用于 Claude Code。

核心场景是"按期刊/文献来源批量导出某时间段全部发文"，也支持任意定制检索（主题、作者、关键词、单位、基金等字段组合 + 年份范围 + 排序方式）后的逐页全选与导出。

> 本 skill 拿的是**结构化题录数据**（18列表格），不是 PDF 全文或单篇引用。下载全文用 `cnki-batch-download` / `cnki-download`，导出单篇引用用 `cnki-export`。

## 功能

- 按**期刊/文献来源**导出某时间段全部发文（如"某CSSCI期刊2020-2026年所有论文"）
- 按任意检索式（主题、篇名、作者、单位、基金等字段组合 + 年份范围）批量导出
- 18 列结构化字段：题名、作者、单位、来源、关键词、摘要、发表时间、基金、卷期页码、中图分类号、ISSN、DOI 等
- 内置合并、去重、核验流程（跨批次合并、按题名去重、逐本核验三要素）

## 安装

```bash
git clone https://github.com/edsion12138/cnkidata.git ~/.claude/skills/cnkidata
```

## 前置条件

1. 浏览器已登录知网（机构/个人登录态，`cnki-journal-search` 需要登录）
2. Chromium 系浏览器可用（bb-browser 驱动）
3. Python 3 环境（用于合并/去重/核验脚本）

## 使用

在 Claude Code 中说：

```
把《高等教育研究》2020-2026 年的全部论文导出成 18 列 xlsx
导出主题=职业教育 且 年份=2024 的所有CSSCI论文
```

## 核心流程（五步）

```
1. 检索设计 → 2. 执行检索+精准锁定 → 3. 核验来源纯净度 → 4. 逐页全选+批量导出 → 5. 合并去重核验
```

## 检索设计要素

| 要素 | 说明 | 示例 |
|------|------|------|
| 检索字段 | 文献来源 / 主题 / 篇名 / 作者 / 单位 / 基金 | 文献来源（期刊） |
| 检索词 | 目标期刊名、关键词、作者名等 | "高等教育研究" |
| 年份范围 | 起止年 | 2020-2026 |
| 排序方式 | 发表时间降序（默认） | 发表时间 |

> **检索词准确性是最大坑**：CNKI 刊名可能用句点而非间隔号（"课程.教材.教法"不是"课程·教材·教法"）；期刊可能更名（按新名搜会漏旧年份）。务必先用 `cnki-journal-search` 或让用户确认准确刊名。

## 18 列字段

```
SrcDatabase-来源库, Title-题名, Author-作者, Organ-单位, Source-文献来源,
Keyword-关键词, Summary-摘要, PubTime-发表时间, FirstDuty-第一责任人, Fund-基金,
Year-年, Volume-卷, Period-期, PageCount-页码, CLC-中图分类号, ISSN, URL, DOI
```

## 关键铁律（防翻车）

- 检索词要准确（标点、更名史）
- 同名期刊用精准复选框锁定（避免"教育学报"混入"比较教育学报"等）
- 选字段后**折叠下拉**（否则遮挡全选复选框）
- 先验纯再批量；停止判断看整页年份（不是首篇）
- 导出格式精确匹配"自定义"（不是"查新（自定义引文格式）"），导出页**再选一次**
- 点 xls 后**等 15 秒**（验证码此刻弹出，需用户手动）
- 批次间导航用"首页+精准翻页"，不要连续点"下一页"
- 合并严格按来源名**精确相等**过滤；最终按题名去重 + 逐本核验
